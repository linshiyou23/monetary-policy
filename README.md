# 货币政策分析框架 · README

## 任务

将 `sources/` 内红塔证券《流动性分析手册》系列 6 份 PDF 梳理为三套整理成果：

1. 现行货币政策框架（横截面：框架的构成）
2. 货币政策框架的演变（制度轴：框架如何变成今天这样）
3. 经济发展阶段与相匹配的货币政策（经济轴：经济阶段如何决定框架）

## 来源与口径（重要决策记录）

- **唯一资料来源为 `sources/` 内 6 份 PDF**：手册一（2022.01，45 页）、手册二（2022.02，28 页）、手册三（2022.03，44 页）、手册四（2022.05，39 页）、手册五（无署名日期的网页打印版，26 页，数据截至 2022 年 3—4 月，内容与系列一致）、手册六（2022.07，43 页）。全部经全文逐页读取后整理。
- **未补充任何外部信息、未做时效更新**（原整理任务要求）。因此"现行框架"沿用报告撰写时的口径；资料覆盖 2022 年 1—7 月，此后央行动态不在整理范围内。
- 三套内容均逐处标注出处（如"手册一 §2.1.1"），可回查原件。
- 原报告个别笔误未照搬：手册一"政府性基金预算收入 9.5 亿元"按占比应为 9.5 万亿元；手册一将 MLF、PSL 系于 2013 年，与手册三（2014 年）不一致，整理二从手册三并加注；手册四 p7"投放频率越低……缺口越小"疑为"越高"之笔误，未引用该句。
- 手册五为网页存档、文件内无机构署名，据行文与数据口径确认为同系列第 5 篇。
- 系列原计划的"货币供应量（M2/社融）解读"篇不在文件夹内，广义流动性内容仅来自手册五、六，属素材缺口。
