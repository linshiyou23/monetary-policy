- **原文摘录逐字核验**：每条引文先按"仅删换行"从 `sources/` 各手册 PDF 的文本提取件中复制，再经脚本断言其为原文的逐字子串（多来源引文按片段在任一来源命中），无一改写；页码取自提取件分页标记。部分表格行取自手册三"图 20 央行各项货币政策工具"一览表的表格行原文。
- **保留的可见出处**：表格下方的〔出处〕徽标及导语中的口径说明不属悬停批注，维持原样。
- **复现**：句子批注 `python -X utf8 src/add_cite_annotations.py`，表格行批注 `python -X utf8 src/add_table_annotations.py`（`--dry-run` 仅校验不写入）。输入为 `sources/txt/` 下的引用清单与引文对照 JSON（`_chunkK/_quotes_K/_tchunkK/_tquotes_K`），均由 PDF 提取件派生、与 PDF 同为仅本地留存，不入仓库。

## 《中国货币政策执行报告》下载（2026-10-20）

- **范围**：2001 年第一季度至 2026 年第二季度共 **102 期**全部到位。央行自 2001 年起按季度发布该报告，此前不存在更早期次；官网栏目页亦仅列出 2001 年起的各期。
- **来源**：中国人民银行官网货币政策司"货币政策执行报告"栏目页（单页列出全部各期），逐期进入文章页提取 PDF 附件下载。每期 PDF 的文章页与附件直链记录在 [`中国货币政策执行报告/source_index.csv`](中国货币政策执行报告/source_index.csv)。
- **命名**：`YYYYQn_中国货币政策执行报告.pdf`，便于按时间排序；官方原标题见索引 `title` 列。
- **核验**：全部 102 份均校验 `%PDF` 文件头与 `%%EOF` 结尾；pypdf 抽查 2001Q1、2008Q1、2013Q2、2019Q4、2022Q4、2026Q2 六期首页，标题、期数、发布日期均正确（如 2019Q4 封面日期 2020-02-19，与官网附件路径一致）。共 81.4 MB。
- **口径注意**：索引 `published_at` 列取自文章页 `createDate` 元信息，个别期为页面重新生成时间而非原始发布日期（如 2019Q4 显示 2025-12-10）；各期原始发布时间以报告封面日期为准。
- **复现**：`python -X utf8 src/download_mpr.py`，可重复运行（已下载且校验通过的自动跳过）。官网防护会重置 Python 原生 TLS 握手，脚本经 curl 抓取。2019Q4 附件挂在官网"沟通交流"栏目且链接为完整 URL，脚本已兼容。

## 专栏文章提取（2026-10-20/21）

各期报告中科普性/教学性的"专栏"文章已逐篇提取，存放于 `中国货币政策执行报告/` 下两个子文件夹（413 篇，文件名 `YYYYQn_专栏N_文章标题.*`，期号前缀便于按时间排序），清单见 [`专栏文章_index.csv`](中国货币政策执行报告/专栏文章_index.csv)（期次、专栏号、标题、PDF 页码、字数、md/PDF 文件名）：

- [`专栏文章/`](中国货币政策执行报告/专栏文章) — 413 篇 Markdown 纯文本，便于检索引用，每篇头部注明期次、页码并链接对应 PDF；
- [`专栏文章PDF/`](中国货币政策执行报告/专栏文章PDF) — 413 篇按版面裁剪的独立 PDF（148 MB），从原件页面裁出，图表、表格、排版原样保留，是每篇文章的完整原文。

- **范围**：2002Q3—2026Q2 共 96 期；2001 年各期与 2002 年前两期无专栏。
- **切分原理**：专栏以"专栏 N 标题"独立标题行开始。2003Q3 起专栏正文用楷体（主文仿宋/宋体、节标题黑体），按字体游走切分，主文段落行（全宽、主文字号、版心左缘）出现即收束；2002Q3—2003Q2 全文宋体无法按字体区分，按"下一个专栏标题或主文节号接续的节标题"收束。文本边界与 PDF 裁剪共用同一套收束位置。
- **核验**：413 篇无空提取、无异常短篇；裁剪 PDF 经三轮视觉验收（首版发现的目录误判、字体乱码、图表混排截断、脚注误判、尾行主文残留等问题全部修复），末轮抽检 12/12 通过；跨时期抽查 2003—2026 多篇起止干净、段落完整、图表无裁切。
- **已知限制**：Markdown 为纯文本层，不含专栏内图表，图表数据以对应 PDF 为准；个别老版式专栏含"一、二、"内部小标题，与主文节标题无版式差别，切分靠节号接续推断，如发现个别篇目起止偏差可用 `--dry-run` 核对后微调。
- **复现**：`python -X utf8 src/extract_mpr_columns.py`（`--dry-run` 仅检测不写文件）。依赖 `pypdf`（下载校验）与 `pymupdf`（版式提取与裁剪）。专栏 md/PDF 均为本地留存，不入仓库（索引 CSV 入库）。
- 2026-10-20 将文件夹 `《中国货币政策执行报告》` 更名为 `中国货币政策执行报告`（去除书名号），`source_index.csv` 内路径已同步。
